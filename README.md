# Учебный каталог книг

Этот репозиторий используется в [лабораторной работе № 3](https://course.denrad.dev/materials/lab-03/): студент предлагает новую карточку книги через fork и pull request.

## Как устроен каталог

- `books/` — отдельный Markdown-файл для каждой книги;
- `BOOK_TEMPLATE.md` — образец полей карточки;
- `.gitignore` — правило для локальных черновиков в `scratch/`.

Пример карточки находится в [`books/example.md`](books/example.md). Придумайте название вымышленной книги в духе классической литературы, её автора, год и короткое описание. Создайте отдельный файл с вашим логином GitHub в имени, например `books/your-github-login.md`, и заполните его по шаблону. Общий список редактировать не нужно. Не меняйте чужие карточки без задания и не добавляйте настоящие пароли, токены или посторонние личные данные.

Откройте pull request из ветки своего fork в основную ветку этого репозитория. После замечания преподавателя исправьте тот же файл, сделайте новый коммит и отправьте его в ту же ветку: открытый pull request обновится.

## Оформление и проверка pull request

Работа индивидуальная: один студент — один PR. Название PR — название книги.
В описании обязательно укажите фамилию, имя и учебную группу, что добавили
и что проверили. Эти данные можно также указать в сообщении коммита, например:
`Добавить книгу «Тени старого сада» — Иванов Иван, ИС-21`.
Отдельное письмо со ссылкой на профиль GitHub не требуется.

Преподаватель проверяет **Files changed** и оставляет review: **Comment** —
вопрос или пояснение, **Request changes** — доработка, **Approve** — одобрение.
При доработке исправьте файл в той же ветке, создайте новый коммит, сделайте
push и ответьте на замечание. Новый PR создавать не нужно.
После одобрения преподаватель выполняет **Merge pull request**. Найдите свою
карточку в `main` этого репозитория. **Closed** без **Merged** означает закрытие
без добавления: прочитайте причину и уточните дальнейшие действия.
